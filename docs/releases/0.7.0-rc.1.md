# MusicUnlocker 0.7.0 RC 1 (`v0.7.0-rc.1`)

MusicUnlocker `0.7.0` is a Windows 11 x64-first, offline-first desktop release
candidate (RC 1). The Git tag identifies the prerelease; binaries and Windows
product version remain `0.7.0`. It preserves source audio, avoids transcoding, never silently
overwrites output, and derives final output extensions from decoded content.

## Distribution options

- **Installer** — `MusicUnlocker-Setup-0.7.0-win64.exe` provides the best
  integrated Windows experience: per-user installation, Start Menu,
  uninstall, and encrypted-file Open With registration.
- **Standalone EXE** — `MusicUnlocker-0.7.0-win64.exe` is the actual
  single-file application. It launches directly without a MusicUnlocker
  installation or extraction and does not register associations.
- **Portable ZIP** — `MusicUnlocker-0.7.0-win64-portable.zip` is the complete
  archive containing the executable, README, license, and third-party notices.

Separate `LICENSE.txt`, `THIRD_PARTY_NOTICES.txt`, and `SHA256SUMS` assets
accompany these distributions.

## Implemented format families

The implementation contains KGM/VPR, NCM, KWM, QMC, TM, Xiami, and Ximalaya
paths. Implemented support is not a claim that every family or variant has
passed real-file validation. QMC STag/MusicEx and KGM V5/KGG inputs can require
explicit request-scoped external material.

Only the evidence recorded in `docs/real-validation.md` is promoted here:

- NCM decode and metadata-aware naming: `REAL_PASS`;

## Local release-candidate validation

- Installer, standalone EXE, portable ZIP, top-level legal assets, and
  normalized checksums were produced together under an exact release-directory
  allowlist.
- The standalone EXE launched alone from a path containing spaces and Japanese
  characters, rendered the UI/icon, reported version `0.7.0`, and generated no
  adjacent files.
- A standalone launch argument containing spaces and Unicode entered the input
  queue, remained `Ready`, and did not create an output directory.
- Standalone and portable launches did not create uninstall, ProgID,
  Capabilities, RegisteredApplications, or sampled UserChoice state.
- The installer passed local per-user install, Start Menu, 49-association,
  argument queue/idle, version, and uninstall regression.
- The portable archive retained its documented four-file internal layout and
  launched from an unrelated Unicode/space path.
- The RC UI rendered at approximately 1100x760 and maximized in explicit Light
  and Dark themes with `zh-CN` and a Unicode/space input path.
