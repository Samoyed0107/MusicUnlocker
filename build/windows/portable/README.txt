MusicUnlocker portable package
==============================

Run MusicUnlocker.exe directly after extracting the complete ZIP.

MusicUnlocker preserves source audio and operates offline for decoding. It
requires the Microsoft Edge WebView2 Evergreen Runtime. If the runtime is
missing, the embedded official Microsoft bootstrapper offers installation.

Preferences remain per-user under the normal Windows configuration directory;
the application does not write preferences beside the executable.
